### 문제 설명

민구는 원소의 개수가 개이고 값이 서로 다른 정수 배열 를 오름차순으로 만들고 싶다.

배열의 번째 원소와 번째 원소끼리 서로 위치를 바꿀 수 있고, 정렬 과정 중 언제든지 최대 딱 한 번 배열 전체의 순서를 뒤집을 수 있다.

원소를 교환하는 것, 배열 전체를 뒤집는 것 모두 번의 횟수로 계산한다.

주어진 배열 를 오름차순으로 만드는데 필요한 최소한의 횟수를 구하여라.

### 입력 

 첫 번째 줄에 배열 의 원소 개수 이 주어진다. 

두 번째 줄에 의 원소 정수 가 공백을 사이에 두고 순서대로 주어진다. 

### 출력 

 첫 번째 줄에 주어진 배열 를 오름차순으로 만드는데 필요한 최소한의 횟수를 출력한다.

### 풀이
```python
import sys
input = sys.stdin.readline

N = int(input())
A = list(map(int, input().split()))

def bubbleSort(arr):
    res = 0
    for i in range(N):
        for j in range(N-1-i):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
                res += 1
    return res

prac1 = bubbleSort(A[:])
prac2 = bubbleSort(A[::-1])+1
print(min(prac1, prac2))
```
