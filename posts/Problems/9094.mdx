### 문제 설명

두 정수 n과 m이 주어졌을 때, 0 \< a \< b \< n인 정수 쌍 (a, b) 중에서 (a2+b2+m)/(ab)가 정수인 쌍의 개수를 구하는 프로그램을 작성하시오.

### 입력 

 첫째 줄에 테스트 케이스의 개수 T가 주어진다. 각 테스트 케이스는 한 줄로 이루어져 있으며, n과 m이 주어진다. 두 수는 0보다 크고, 100보다 작거나 같다.

### 출력 

 각 테스트 케이스마다 문제의 조건을 만족하는 (a, b)쌍의 개수를 출력한다.

### 풀이
```javascript
const fs = require('fs');
const input = fs.readFileSync(0, 'utf-8').toString().trim().split('\n');
// const input = fs.readFileSync('input.txt').toString().trim().split('\n');
const [N, ...num] = input.map((n) => n.split(' ').map(Number));

for (const [n, m] of num) {
  console.log(check(n, m));
}

function check(n, m) {
  let ans = 0;
  for (let i = 1; i < n - 1; i++) {
    for (let j = i + 1; j < n; j++) {
      if ((i * i + j * j + m) % (i * j) == 0) {
        ans++;
      }
    }
  }
  return ans;
}
```
